# Security Policy

## Scope

This repository is tool configuration: ripgrep flags, a zsh script for fzf, a lazygit config and
setup instructions. It contains no service and no library. In scope:

- A config value or script that runs something other than what the README documents
- A setup instruction that would leave insecure file permissions behind

## Out of scope

- A vulnerability in ripgrep, fzf, lazygit or zoxide themselves, report that upstream

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
